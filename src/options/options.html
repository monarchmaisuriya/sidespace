      Sites that refuse to be embedded

      Many sites forbid being shown inside another page. With this on, Sidespace removes the X-Frame-Options header, and a Content-Security-Policy that contains frame-ancestors, only for pages the panel loads and same-site navigations inside them. Pages in normal tabs are never changed. For those panel pages the site's own Content-Security-Policy no longer applies.

      Keyboard

      Open the panel: Alt+Shift+S. Open the current page in the panel: Alt+Shift+D. Change these at chrome://extensions/shortcuts.

      Inside the panel: Alt+L address bar, Alt+T new tab, Alt+W close tab, Alt+R reload, Alt+← / Alt+→ back / forward, Alt+1 to Alt+9 switch tab.
